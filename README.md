# Diet & Weight Tracker

50-day South Indian diet plan, daily food checklist, weight tracking, weekly grocery list and batter guide.
Works offline once installed. Data is stored on your phone only.

## Publish with GitHub Pages
1. Create a new public repository (for example `diet-tracker`).
2. Upload all files from this folder to the repository root.
3. Go to Settings > Pages > Source: "Deploy from a branch", Branch: `main`, Folder: `/ (root)`, then Save.
4. After about a minute your app is at `https://YOUR-USERNAME.github.io/diet-tracker/`.

## Install on Android
Open that link in Chrome, tap the three dots, then "Install app" (or "Add to Home screen").
